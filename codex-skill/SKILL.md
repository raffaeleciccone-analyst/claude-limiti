# Usage limits

Generated by claude-limiti's `install.mjs` for Codex and other agents that read `~/.agents/skills`.
The scripts only read data: Codex's session files in `~/.codex/sessions` (or `$CODEX_HOME`) and,
if Claude Code is installed, the state of its status line in `~/.claude/state`.

Always reply in the user's language, in a few simple lines.

## Showing the limits

1. Run exactly: `node "{{DIR}}/report.mjs"`
2. Summarize the output simply. Put any history chart in a code block so it stays aligned.
3. If the output starts with `NESSUN_DATO` or `NO_DATA`: explain that Codex writes its limits after
   the first response of a session, only when signed in with a ChatGPT account (not with an API key).
   `/status` in the Codex CLI shows the same limits.
4. The Codex section says how old the data is: it only updates when Codex is used. If it is hours
   old, say so; the limit may have moved since.
5. Give at most one tip, only when useful:
   - a window used much faster than the time elapsed (more than 10 points above the pace) ->
     spread the work, or switch to a lighter model / lower reasoning effort for simple tasks;
   - everything on pace or below -> just say so.

## Settings

Codex has no customizable status line, so here only the report is available. The settings script
(`node "{{DIR}}/settings.mjs"`) changes the Claude Code status line and the language
(`node "{{DIR}}/settings.mjs" language it`). Pass only a key and a value from the options it lists.
